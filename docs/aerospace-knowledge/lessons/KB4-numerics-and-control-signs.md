# 工程课 KB4｜一张收敛表，学懂机械振动、控制工程与数值仿真

> 对应 [KR-2026-005](../records/KR-2026-005-nonlinear-convergence.md)、[KR-2026-006](../records/KR-2026-006-polarity-contract.md)。来自 2026-10-29 **已经实际执行的纯软件数学实验**。不要将理论示例用于任何物理推进/飞行控制调参。

## 先有现实问题，再学公式

你看到的历史项目曲线写着“仿真结果 PASS”，应当先问三个问题：

1. 我用**更小的时间步长**再算一次，结果是否接近？
2. 我换**独立的计算方法**来算同一条方程，结论是否一致？
3. 即使答案相同，这条方程是否**真的代表当前硬件**？

这三个问题分别针对：数值收敛、交叉校核、物理验证。第三个问题不能靠前两个自动解决。

## 第 1 节｜倒立摆模型从哪里来？

假设一个绕固定轴转动的简化倒立摆，角位移 \`theta\`，角速度 \`omega=theta'\`，转动惯量 \`I\`，质量 \`m\`，重心到支点距离 \`L\`，阻尼 \`c\`，重力加速度 \`g\`。

用角动量定理（固定轴）得到：

\`\`\`text
I * theta'' = m*g*L*sin(theta) - c*theta'
\`\`\`

其中 \`m*g*L*sin(theta)\` 在本模型规定的正向上为**倾覆力矩**，\`-c*theta'\` 表示与角速度相反的阻尼力矩。当前实验的**实际推力设置为 0 N**，没有舵机或闭环控制。

这不是“火箭飞行方程”。它只是项目过去选择的一维教学/试验原型模型。

将二阶方程写成一阶向量微分方程，这是求解器真正接收的输入：

\`\`\`text
y = [theta, omega]
y' = [omega, (m*g*L*sin(theta)-c*omega)/I]
\`\`\`

工程软件里所有 \`theta\`、\`omega\` 都应明确使用 \`rad\`、\`rad/s\`，否则“公式正确”也会被单位混用破坏。

## 第 2 节｜为什么少量初始角度会放大？

在很小的角度范围内，\`sin(theta)≈theta\`，于是：

\`\`\`text
I*theta'' + c*theta' - m*g*L*theta = 0
\`\`\`

如果设 \`theta=exp(r*t)\`，得到特征方程：

\`\`\`text
I*r² + c*r - m*g*L = 0
\`\`\`

由于常数项为负，该方程在正的 \`m, g, L, I\` 下具有**一正一负两个实根**。正根对应增长的指数项，也就是这个理想倒立摆不加任何主动作用时**本身不稳定**。

使用历史研究参数 \`m=1 kg\`、\`L=0.2 m\`、\`c=0.5\`、\`g=9.81\`，假设 \`I=(1/3)*m*(2L)²≈0.05333 kg·m²\`，线性化正特征根约 \`2.978 s⁻¹\`。它只描述**此原型模型的局部不稳定性**，不是实物时间常数。

实际 KB4 在非线性计算中，从 \`0.5°\` 出发，到 \`1.2 s\` 时约 \`14.3173°\`。这也说明小角度近似不宜在整个过程直接当作精确真值。

## 第 3 节｜为什么步长减半，误差接近 16 倍缩小？

原项目的 \`physics_engine.py\` 用的是四阶 Runge–Kutta（RK4）。对足够光滑的常微分方程、有限时间范围与合适步长，**全局截断误差**通常满足：

\`\`\`text
error(h) ≈ C * h^4
error(h) / error(h/2) ≈ 2^4 = 16
\`\`\`

在本轮真实试验里：
- \`h=0.08s\`：角度误差约 \`1.865×10⁻⁵ rad\`；
- \`h=0.04s\`：约 \`1.292×10⁻⁶ rad\`；
- \`h=0.02s\`：约 \`8.511×10⁻⁸ rad\`；
- \`h=0.01s\`：约 \`5.461×10⁻⁹ rad\`。

误差改善比为 \`14.43 → 15.18 → 15.58\`，逐渐靠近 16。为什么不是精确 16？因为步长还没完全进入渐近误差主导区，比较参照本身也只有有限容差，还存在浮点舍入。

**重点不是“步长越小必然越好”。** 当步长非常小时，浮点舍入、计算成本与模型偏差也会影响结论；工程上要根据目标精度、计算资源和误差来源作取舍。

## 第 4 节｜为什么换两种求解器也不代表真实火箭正确？

这次 DOP853 和 Radau 求解的是同一非线性方程，但采用不同的数值算法。两者接近到 \`~3.08×10⁻¹³\` 的状态分量最大差异，支持**数值求解一致性**，并不能证明：
- 质量或转动惯量真的测对了；
- 阻尼模型在真实装置上成立；
- 舵机方向和喷流力矩经过测量；
- 真实机架、传感器、供电、温度和结构边界是安全的。

因此要牢记：

**“解方程解对了” ≠ “方程描述了真实世界” ≠ “产品能够安全运行”。**

NASA-STD-7009B 对模型/仿真的可信性强调用途、模型、证据和决策边界；本研究以此为方法参考，**不声称已经满足 NASA 标准的完整要求**。

## 第 5 节｜为什么学控制工程时，符号比 PID 数值更重要？

在历史 1D 模型中，正舵角通过 \`-F*Lt*sin(servo)\` 施加负方向力矩。假设当前角度 \`theta>0\`，通常误差 \`e=0-theta<0\`。如果把 \`PID(e)\` 不经约定直接当舵角，则比例项为负，而其对应的模型力矩为正，**可能进一步增加正角度**。

因此必须先规定：坐标正向、误差正向、输出正向、执行器到实际力矩的符号变换。没有“方向合同”，即使把 PID 调得再漂亮，结果也没有可迁移性。现有 \`param_sweep.py\` 与 \`test_polarity.py\` 符号调用不一致已归档，但**真实舵机、安装和受力的方向仍然 UNKNOWN**。

## 理解检测

1. 两种求解器给出完全一样的结果，为什么仍不能证明真实装置准确？
2. 对四阶 RK4，若步长从 \`0.02s\` 缩减为 \`0.01s\`，在渐近误差区预期误差大约变为原来的几分之一？
3. \`theta>0\`，若数学模型规定正舵角贡献负方向力矩，你在设定 \`e=目标-测量\` 时最先应该确认哪些接口方向？

正确完成这三题，你就不只是能背出微分方程，而是开始具备**审查一份工程仿真报告是否值得信任**的能力。
