💻 软件模块

主循环结构 (20Hz / 50ms每帧)

// 主循环 - 飞行计算机核心 void loop() { // 1. 读取串口指令 (ESP8266 + USB) readSerialCommands(); // 2. ESTOP 安全检查 if (estop_active) return; // 3. 读取传感器 readMPU6500(); // 陀螺仪 + 加速度计 readBMP280(); // 气压 → 高度 // 4. 姿态解算 (atan2) pitch_raw = atan2(-ax, sqrt(ay² + az²)) × 180/π; roll_raw = atan2(ay, az) × 180/π; // 5. 卡尔曼滤波 pitch_flt = kalmanFilter.update(pitch_raw, gyro_y); roll_flt = kalmanFilter.update(roll_raw, gyro_x); // 6. 飞行状态机更新 fsm.update(az, altitude, millis()); // 7. PID 控制 (自动模式) if (auto_mode && !chute_deployed) { servo_pitch = pidPitch.compute(pitch_flt); servo_roll = pidRoll.compute(roll_flt); } // 8. JSON 遥测输出 sendTelemetry(); delay(50); // 20Hz }

积分限幅: ±30° | 微分滤波: 50ms 延迟补偿

⚠️ PID 调参警告

由于 50ms 卡尔曼延迟和 SG92R 死区，高重心 (0.5m) 下无法稳定。必须将重心压低至 ≤ 0.2m，并建议从纯 PD 控制开始 (Ki=0)。

📨 通信协议

上行指令 (地面站 → 飞控)

纯文本格式，换行符结尾，波特率 115200

指令 格式 说明
set_servo set_servo:pitch,roll 手动设置 TVC 舵机角度 (0-180)
set_pid set_pid:kp,ki,kd 动态调整 PID 参数
estop estop 紧急停机，舵机归中
reset reset 解除停机，恢复输出
auto_on auto_on 开启 PID 自动姿态稳定
auto_off auto_off 关闭 PID，舵机归中
arm arm 进入待发射，校准地面高度
deploy_chute deploy_chute 手动触发开伞

下行遥测 (飞控 → 地面站)

JSON 格式，20Hz 发送

{ "time": 123456, // 毫秒时间戳 "pitch_raw": -6.39, // 原始俯仰角 (°) "pitch_flt": -6.21, // 滤波后俯仰角 (°) "roll_raw": -130.04, // 原始滚转角 (°) "roll_flt": -129.87, // 滤波后滚转角 (°) "yaw": -1.05, // 偏航角 (°) "alt": 142.73, // 高度 (m) "auto": 1, // 自动模式 (0/1) "chute": 0, // 开伞状态 (0/1) "fstate": "COAST", // 飞行状态 "batt": 7.4 // 电池电压 (V) }

关键技术要点

1

重心控制

高重心 (0.5m) 无法稳定，必须将重心压低至 ≤ 0.2m 才能让 PID 收敛

2

延迟补偿

50ms 卡尔曼延迟是控制系统的致命瓶颈，强 P 会引起正反馈爆炸

3

舵机选型

SG92R 死区 ±0.5°，50Hz 刷新率，限制控制带宽

4

安全第一

所有物理测试必须加牵引绳，从保守 PID 参数开始
