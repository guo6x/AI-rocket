## 1. 降落伞设计

### 1.1 所需伞面面积计算

降落伞稳态下降速度满足力平衡方程：

```
mg = ½ · ρ · v² · Cd · S
```

解出所需伞面面积：

```
S = 2mg / (ρ · v² · Cd)
```

其中：
- `m` = 箭体质量 (kg)
- `g` = 9.81 m/s²
- `ρ` = 空气密度 ≈ 1.225 kg/m³ (海平面)
- `v` = 目标着陆速度 (m/s)
- `Cd` = 阻力系数（取决于伞型）
- `S` = 伞面参考面积 (m²)

#### 计算结果表

| 箭体质量 | 目标速度 | 伞型 | Cd | 所需面积 S | 等效直径 D |
|---|---|---|---|---|---|
| 0.5 kg | 5 m/s | 十字伞 | 0.65 | **0.491 m²** | **0.79 m** |
| 0.5 kg | 5 m/s | 圆伞 | 0.80 | **0.399 m²** | **0.71 m** |
| 1.0 kg | 5 m/s | 十字伞 | 0.65 | **0.982 m²** | **1.12 m** |
| 1.0 kg | 5 m/s | 圆伞 | 0.80 | **0.798 m²** | **1.01 m** |
| 1.0 kg | 4 m/s | 圆伞 | 0.80 | **1.247 m²** | **1.26 m** |

> 详细推导示例 (1 kg / 5 m/s / 圆伞)：
> `S = 2 × 1.0 × 9.81 / (1.225 × 25 × 0.80) = 19.62 / 24.50 = 0.80 m²`
> `D = √(4S/π) = √(4 × 0.80 / 3.14) = 1.01 m`

### 1.2 伞型推荐

| 伞型 | Cd | 稳定性 | 制作难度 | 推荐指数 |
|---|---|---|---|---|
| **十字伞** | 0.6–0.7 | ★★★★★ 极好，几乎无摆动 | ★★☆☆☆ 简单，缝纫量少 | ⭐ **首选** |
| 圆伞（平顶） | 0.75–0.85 | ★★★☆☆ 容易摆荡 | ★★★☆☆ 中等 | 备选 |
| 环缝伞 | 0.5–0.6 | ★★★★☆ 好 | ★★★★★ 困难，需精密缝纫 | 不推荐 |

**✅ 最终推荐：十字伞 (Cruciform Parachute)**

理由：
1. **稳定性极佳**——十字伞的交叉布面破坏了涡脱落的对称性，天然抑制钟摆振荡，箭体不会在空中大幅摆荡
2. **制作极简**——两条矩形布料十字交叉缝合即可，无需裁剪弧形裁片
3. **失效安全**——即使一条臂略有撕裂，另一条臂仍能提供大部分阻力
4. **Cd 足够**——0.65 对于我们的质量范围，伞面直径控制在 0.8–1.1 m，体积完全可以塞入箭体头锥

### 1.3 尺寸与材料规格

以 **1 kg 上限质量**为设计基准（留安全裕度）：

| 项目 | 规格 |
|---|---|

| **每条臂尺寸** | 100 cm × 35 cm (长 × 宽，基于1kg安全裕度) |

## 3. 触发逻辑设计

### 3.1 三重冗余方案

为确保降落伞可靠开伞，设计**三重独立触发通道**，任意一条触发即执行弹射：

```
                    ┌─────────────────┐
  方案A ──────────►│                 │
  (气压顶点检测)     │   OR 逻辑门     │────► deploy_chute()
  方案B ──────────►│   (任一即触发)    │
  (发射后定时器)     │                 │
  方案C ──────────►│                 │
  (地面站手动指令)   └─────────────────┘
```

### 3.2 方案 A：弹道顶点检测（主触发——推荐）

**原理**：BMP280 气压计持续读取高度值，当检测到高度连续下降时判定已过顶点。

**算法伪代码**：

```cpp
// ===== 回收触发状态机 =====
enum RecoveryState { ARMED, COAST, DEPLOYED };
RecoveryState recovery_state = ARMED;

float alt_history[5] = {0};  // 最近5次高度采样
int alt_idx = 0;
float launch_alt = 0;        // 发射前地面高度基准
bool chute_deployed = false;
unsigned long launch_time = 0;

void checkApogeeDetection(float current_alt) {
    if (chute_deployed) return;

    switch (recovery_state) {
    case ARMED:
        // 检测到离地：高度比基准高 >10m → 进入滑行段
        if (current_alt - launch_alt > 10.0) {
            recovery_state = COAST;
            Serial.println("[RECOV] COAST phase entered");
        }
        break;

    case COAST:
        // 滚动窗口记录高度
        alt_history[alt_idx % 5] = current_alt;
        alt_idx++;

        // 至少采集5个点后才判断
        if (alt_idx >= 5) {
            // 检查最近5个点是否全部递减 (顶点已过)
            bool all_descending = true;
            for (int i = 1; i < 5; i++) {
                if (alt_history[i % 5] >= alt_history[(i - 1) % 5]) {
                    all_descending = false;
                    break;
                }
            }
            if (all_descending) {
                deployChute("APOGEE_DETECT");
            }
        }
        break;

    case DEPLOYED:
        break;
    }
}
```

**关键参数**：
- 离地判据门槛：Δh > 10 m（滤除地面噪声）
- 顶点确认窗口：连续 5 个采样点高度递减（20Hz 采样 = 250ms 窗口）
- BMP280 高度噪声：±0.5 m（已配置 x16 过采样，足够精确）

### 3.3 方案 B：定时器触发（备份安全网）

**原理**：发射后固定延时强制开伞，防止气压计失效时箭体自由落体。

```cpp
const unsigned long TIMER_DEPLOY_MS = 15000; // 发射后15秒强制开伞

void checkTimerDeploy() {
    if (chute_deployed) return;
    if (recovery_state != ARMED) { // 已检测到离地
        if (millis() - launch_time > TIMER_DEPLOY_MS) {
            deployChute("TIMER_BACKUP");
        }
    }
}
```

> [!TIP]
> 定时器时长需根据实际发动机燃烧时间 + 预估滑行时间设定。典型探空火箭：
> 燃烧时间 ~2-3s + 滑行至顶点 ~5-8s + 安全裕度 ~5s ≈ **15s**

### 3.4 方案 C：地面站手动指令（最终人工安全阀）

**原理**：操作员在地面站 UI 上点击「开伞」按钮，通过 WiFi 链路发送指令。

已有通信链路完整支持此方案：

```
地面站 Python UI → UDP → ESP8266 → Serial → STM32
                       指令: "deploy_chute\n"
```

**飞控端新增指令处理**：

```cpp
// 在 processCommand() 函数中新增:
} else if (cmd == "deploy_chute") {
    if (!chute_deployed) {
        deployChute("GROUND_CMD");
    } else {
        Serial.println("[RECOV] Chute already deployed. Ignored.");
    }
}
```

### 3.5 核心弹射执行函数

```cpp
Servo servoRecovery;  // PB0

void deployChute(const char* trigger_source) {
    chute_deployed = true;
    recovery_state = DEPLOYED;

    // 1. 舵机旋转拔销
    servoRecovery.write(0);   // 从90°(锁定)转到0°(拔出阻挡销)
    
    // 2. 遥测通知
    Serial.print("[RECOV] !!! CHUTE DEPLOYED !!! Trigger: ");
    Serial.println(trigger_source);
    
    // 3. TVC舵机自动归中（下降段不再需要姿态控制）
    auto_mode = false;
    servoPitch.write(90);
    servoRoll.write(90);
}
```

## 7. 地面测试计划

在装载到箭体之前，建议按以下顺序进行地面验证：

### 测试 1：纯舵机拔销测试
- 将舵机 + 阻挡销 + 弹簧组装在桌面上
