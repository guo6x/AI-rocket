## 1. 物理环境与挑战建模

为了防止主设备在直接上机调参时损毁，我们在纯 Python 环境中构建了带执行器非理想特性的 1000Hz RK4 数值微分仿真。

- **火箭抽象**: 1kg，重心高度 0.2m (降低重心以适配劣质执行器)。
- **航电卡尔曼滤波模型**: MPU6500 的积分和计算滞后被建模为严格的 **50ms 绝对延迟** 与 **20Hz** 低频更新率。这意味着控制解算用到的总是 0.05 秒前的残缺角度。
- **作动器模型**: 采用 SG92R 烂舵机数学模型，包含 $0.5^\circ$ 死区，并且被限速为最大 $600^\circ/s$ (空载指标)，PWM 刷新率 $50\text{Hz}$。

## 2. 仿真验证与重要发现
 
我们在修正了控制极性（Negative Feedback）后，重新评估了 50ms 延迟下的稳定性。
 
### 重心高度 (CG) 的决定性影响
 
通过 `cg_impact_study.py` 的对比实验，我们发现了“倒立摆控制的深渊区”：
- **低重心 (0.1m - 0.2m)**: 系统响应极快，50ms 的滞后导致 PID 计算出的指令总是滞后于物理状态，产生严重的**正反馈震荡**，系统迅速发散。
- **高重心 (0.5m - 0.8m)**: 系统的角加速度降低，虽然控制力矩也有所下降，但系统变得“缓慢而稳重”，50ms 的延迟在慢速系统中不再致命，PID 能够轻松收敛。
 
### 结论：坚定执行“高重心”方案
 
为了让 TVC 倒立摆测试台最容易收敛，我们**必须将重心尽量上移**。
 
- **推荐 CG 位置**: 距枢轴以上 **50cm ~ 70cm**。
- **推荐 PID 系数 (基于 50ms 延迟/50Hz 舵机)**:
  - `Kp = 1.5 ~ 2.0`
  - `Ki = 0.0`
  - `Kd = 0.4 ~ 0.6` (强 D 项对于抑制延迟引起的超调至关重要)

> 附推荐测试起点（针对 0.5m 重心）：`Kp=1.65, Ki=0.0, Kd=0.45`
